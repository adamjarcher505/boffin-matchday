# Boffin Matchday

Adam's football quiz game. Mobile-first web app, plain HTML/CSS/JS, no build step, no framework.
Moved here from a claude.ai artifact (https://claude.ai/code/artifact/5be71bbb-820c-4ce6-8f77-f2bcb3f9f007) on 11/11/2026.

## What it is
- AAA-feel football quiz. Core loop: play "matches" (5 chances + penalty) made of mixed question types, earn XP, level up, climb divisions.
- Divisions: Sunday League → Non-League → League Two → League One → Championship → Top Flight → European Nights…
- Modes: league season (19 games, promotion/relegation vs house sides + real players), Club Cup (R16 → Final vs fans of your own club), Club Wars weekly scores, sticker album (Panini-style) of players you name.
- Tone: tongue-in-cheek terrace banter, not cringe. Audience: football casuals, young lads to men in their 30s. UK English.
- Look: "Floodlights" skin — graphite panels, amber LED scoreboard, Big Shoulders Display / Inter / Share Tech Mono. Dark only, on purpose.

## Files
Full map and data model in README.md. Judgment calls in DECISIONS.md; what's blocked in BLOCKED.md; Adam's to-do in HANDOVER.md.
- `index.html`: markup only. Script order: config, data, questions, sticker-pages, kits, then `src/`: core, state, fx, career, league, generators, rounds, rounds-more, match, grid, chain, screens, events, extras, stickers, net, boot. Plain scripts sharing globals; order matters.
- `src/styles.css`: all CSS. Newest sections at the bottom, dated.
- `src/core.js`: data lookups, `TYPES`, helpers, player search. `CLUBS_PICK` = pickable clubs.
- `src/state.js`: `TUNING` and `STICKER_RULES` (balance numbers); save format `SAVE_V` (now 3) + `MIGRATIONS` + `hydrate` + `mergeSaves`.
- `src/fx.js`: `sfx` (synthesised sound), `crest()`, `commentary()`, `TALK` lines. Feel only.
- `src/career.js`: streak (`S.sk`), daily objectives (`OBJ`, `S.ob`), medals (`MEDALS`, `S.md`), season awards. XP only; numbers in `CAREER`.
- `src/league.js`: `leagueTable`, `settleSeason`, house sides.
- `src/generators.js`: `makeMatch`, `makeRound`, `makeScoped`, `makeCupMatch`, seeded with `rngOf(hash(...))`. `EASE` = fair-for-the-division limits (tuned with `node tools/difficulty.js`).
- `src/rounds-more.js`: makers + runtimes for the 14/11 types (`MORE_TYPES`: six, pals, fake, buy, row, order, flags, exact), team-mate lookups (`tmOf`), flags. `src/chain.js`: Chain Reaction daily game.
- `src/rounds.js`: `RUN` (how each type plays). `src/match.js`: match engine, verdict, full time; `QV` = question-generator version (bump whenever a seed's questions change). `src/grid.js`, `src/screens.js`, `src/events.js`.
- `src/extras.js`: share cards, season stakes and Final Day, "around you" lines, training XP cap, Club Wars (top 10 ÷ 10), question log, theme of the day (`THEMES`, `THEME_ROTA` from `tools/theme-support.js`), haptics.
- `src/stickers.js`: sticker album (`S.stk`), offers after matches, the "name the man on the sticker" attempt, pages, swaps, tokens. Separate from the Names log (`S.album`).
- `questions.js`: GENERATED by `data-pipeline/` (open data, two sources per question; SOURCES.md). Never hand-edit. Read by `QB` in app.js; played by the Pub Quiz type (`makeQuiz`, `RUN.quiz`). `QV` includes its version.
- `data-pipeline/`: build-time only. `node --no-warnings data-pipeline/run.mjs` → fetch, SQLite build, generate + reports. Weekly GitHub Action opens a PR, never pushes main.
- `kits.js`: `BOFFIN_KITS`, home shirts for the sticker clubs (sourced, see header); `kitFor`/`kitSVG` in stickers.js pick the era and draw it.
- `sticker-pages.js`: FROZEN album pages. Never regenerate once players have stickers; `node tools/make-sticker-pages.js --add` only adds clubs.
- `src/net.js`: `Net` over three backends (supabase / claude artifact db / local). Sync is pull-merge-push. Features needing `supabase/002_additions.sql` fail soft.
- `src/boot.js`: start-up, service worker, "New version ready" toast.
- `sw.js`: versioned cache-first offline cache. **Run `node tools/bump-sw.js` before every deploy.**
- `config.js`, `manifest.webmanifest`, `icons/`, `supabase/` (schema.sql, 002_additions.sql, make-founder.sql), `tools/`, `tests/` (dev-only).
- `data.js`: `window.BD`, ~1.5 MB of real football data. Don't hand-edit; no build script exists (BLOCKED.md). Club trails miss some moves, so never show departure years.
  - `players` 15,337 rows: `[name, natIdx, pos, birthYear-1900, fame×10, clubSpells[club, year-1990,...], seasonSpells[club, from, to,...], flags]`
  - `clubs` 1,358, `nats` 157, `leagues` 5; `lists` 236 top tens, `xi` 839 line-ups, `tables` 109 (top four + relegated only), `hl` 900 fees, `pairs` 700, `gridClubs`, `gridNats`.

## Running it
Serve the folder: `node tools/dev-server.js` (no caching; launch config `boffin`), open `/?offline` so tests don't touch the live Supabase. The service worker serves cached files: unregister it and clear caches before testing changes. Tests: `cd tests && node --test unit/*.test.js`; headless browser run (full match, cup tie, no-scroll at three sizes): `node tests/browser/run.js`.
